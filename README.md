# usewndr.com

The public website and macOS download for Wander.

Wander gives you one interesting question at a time while your AI works. Press `Option-W` from any app to open or close it.

## Local preview

```sh
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173`.

## Release file

The website expects the notarized universal DMG at:

```text
download/Wander-0.1.0.dmg
```

Update the download links and version copy together when publishing a new release.
